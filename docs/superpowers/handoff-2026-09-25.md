## 5. Hard lessons (do not relearn)

- PowerShell 5.1: no `&&`, no `Get/Set-Content` on UTF-8 files (mojibake —
  use python or Edit; `Set-Content` also adds BOM). Quote with `"`.
- `git diff -- <paths> --output=F` is broken (flag after `--` becomes a
  path); use `git diff --output=F -- <paths>`. Export must hash-match the
  ledger line or re-export+reseal in the same flow.
- New live files need `git add -N` before `git diff` sees them (intent-to-add
  also breaks `hermes update`'s stash → reverse-apply + targeted
  `git reset <paths>` (index-only, allowed) before updating.
- Detached `Start-Process` + `>> log` redirection silently produces empty
  logs on first try sometimes; verify log non-empty before polling.
- Atomic commits = one reason (canary must stay trivially revertible;
  `30fb6a4` bundle violated this — revert recipe in
  `docs/canary/2026-09-11-fantrax-canary-revert.md`).
- HIT iterations write NO trace (`_pending_trace = None`) — trace counts
  are MISS-only; never infer HIT rates from traces, use agent.log bursts.
- `verify()` green requires reseal AFTER every intended change; `doctor`
  splits byte_integrity vs fleet_consistency structurally — keep it that way.
